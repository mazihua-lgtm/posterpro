# PosterPro

面向公众号的选题、文案与封面图内容工厂。

## 能做什么 / What it does
- 提供职场、女性、副业、亲子、养生选题
- 生成 900×383 公众号封面
- 按模板输出标题、钩子与文案

## 快速使用 / Quick Start
```bash
pip install Pillow
python3 posterpro.py make 搞钱副业 0
```

## 示例输出 / Example Output
```text
✅ 封面与文案已生成
```

## 技术栈 / Tech
- Python 3.9+、Pillow

## 适用场景 / Use Cases
- 公众号选题测试、批量内容生产
